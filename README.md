### 참고 - 커밋 메시지 주요 키워드

- Add : 기능 추가 시
- Setting : 초기 설정 등 설정 시
- Modify : 기능 수정 시
- Fix : 배포 후 버그가 발견되어 배포가 중지될 경우.
- Doc : README 수정 시
- Test : Test 코드 작성 시
- Refactor : 리팩토링 시
- Remove : 기존 코드 제거 시
